# 从基础到困难的验证

测试全部执行后生成 [机器报告](../examples/tests/report.json) 和 [逐项输出](../examples/tests/unittest.txt)。浏览器交互有单独 [报告](../examples/browser/report.json) 与桌面/手机截图。

| 层级 | 文件 | 覆盖内容 |
| --- | --- | --- |
| 基础与核心守卫，32 项 | tests/test_planning.py | 正常、信息缺失、12→8、失败、无解、重复、脚本/保存续跑；整数费用、已花成本、越权、依赖、事务失败、模型失败、并发租约、时间流逝、步数上限 |
| 边缘与困难，14 项 | tests/test_edges.py | 截止恰好相等/少 1 微秒、跨午夜、等价时区/金额、失败和估算耗时、旧租约所有者、连续两次失败、保存后模型错误/达到上限、恶意工具动作、合法参数纠错反馈、真正两个子进程续跑、远端明文拒绝、非法模型响应 |
| HTTP，12 项 | tests/test_web.py | 页面/手册、API 前缀 404、任务/重复、失败续跑、修改输入冲突、跨站和 Host、非法 JSON/目录、缺信息、并发、服务重启持久化、路径边界 |
| 浏览器，22 项 | scripts/browser-smoke.cjs | 真实 Chrome 点击、重复、下载、刷新、原请求续跑、预算缺口、失败状态、保存续跑、非法 JSON、主题转义、手机宽度、手册、控制台异常 |

故障注入位于合成目录 `failures`，按工具及套餐指定前 N 次失败，计数随请求持久化。失败注入发生在实际工具路径中，结果交还模型；不是预设成功日志。存储失败测试另用 SQLite trigger 在 INSERT 时真实中断事务，验证无方案记录、无保存收费、成功脚本保留，移除故障后可恢复。

费用测试独立核对事件整数金额之和、总费、保存方案总费、预算上限，覆盖换套餐后已花成本不得归零。时间测试采用固定时钟保证可重复，真实样例与网页采用实际系统时间。

攻击性动作测试使用明确标注的测试模型，证明工具边界不会被恶意动作绕开；不据此声称真实 Qwen 的提示注入防御已全面评估。浏览器转义测试只证明文字安全渲染。

真实模型与离线断言分离；CI 不下载模型，检查纯业务与 UI。真实运行样例在评估文档引用，不能用测试模型冒充模型决策。


追加边缘困难测试 `tests/test_hardening.py`：12 项，覆盖精度、空白约束、目录结构、自定义套餐、真实模型动作阶段、过期续跑、并发和零费用。本轮结果及真实模型失败/修复详见 [追加测试报告](09-hardening-round.md)。
