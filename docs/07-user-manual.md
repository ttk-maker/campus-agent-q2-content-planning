# 内容任务规划工作台使用手册

在仓库目录执行 `py -3.10 -m src.web`，打开 http://127.0.0.1:8767/ 。完整网页手册为 http://127.0.0.1:8767/manual.html，源文件是 [web/manual.html](../web/manual.html)。模型地址 http://localhost:11434/v1 是 API 前缀，直接打开 404 不是工作台损坏。

## 操作步骤

1. 选场景或填主题、预算、截止时间。截止时间显示浏览器本地时区，传输用带时区时间戳；预算留空不会擅自补默认值。
2. 先用“离线演练”核对界面；再选“真实模型”，确保 Ollama 与 Qwen 可用。
3. 点击“开始规划”。结果展示实际费用、已选方案、步骤状态和保存状态；只有实际保存有方案 ID 才显示已保存。
4. 展开 Trace 查看每步动作、参数、观察摘要、后续动作和简短依据。“导出运行记录”包含原请求、工具配置、结果和完整 Trace。
5. “续跑 / 重复执行原请求”永远使用上一次提交的原始输入，不读取当前编辑中的新值。失败时保留成功步骤；已完成时返回原方案且不增加费用。
6. 若要修改预算、截止时间、主题或配置，应点击“生成新 ID”后运行。相同 ID 的不同输入会被拒绝，报 `idempotency_conflict`。缺信息补齐后也要新建 ID。

## 场景与预期

| 场景 | 离线演练结果 | 操作 |
| --- | --- | --- |
| 预算 10 | 高级 12 超限，改基础 8 并保存 | 查看估算与选择动作 |
| 正常预算 20 | 高级 12 保存 | 检查依赖和总费用 |
| 缺预算/截止时间 | 待补信息，0 费用 | 补信息后新建 ID |
| 高级脚本失败 | 检索结果保留，改基础，8 保存 | 查看失败仍在步骤与事件中 |
| 预算 7 | 无可行方案，最小预算缺口 1 | 用户决定是否更改要求 |
| 仅剩 3 分钟 | 无可行方案，显示超时 | 新建时间可行的请求 |
| 基础脚本失败一次 | 第一次失败，费用 2；续跑后完成，总费 8 | 用续跑按钮，勿重新选场景 |
| 保存失败一次 | 第一次失败，费用 6；续跑后保存，总费 8 | 不重新生成脚本 |

真实模型可选择同轮重试、替代或停止，因此路径可能不同；应核对实际状态与事件，而不是要求每个按钮都产生固定日志。

## 恢复、费用与故障排查

默认业务数据库为 `runtime/workbench.db`。同一库及相同输入可跨进程继续；换库相当于新的独立环境。浏览器保存最近请求，刷新恢复当前任务；服务重启后运行记录不存在时会提示，可将保留的相同请求重新提交。内存运行列表只保留最近 100 条，长期证据请导出。

成本：检索 2 + 脚本高级 8 / 基础 4 + 保存 2。失败零费但耗时 1 分钟。更换套餐不能抹去已成功的费用。截止检查包含累计模拟耗时和真实模型延迟，详见 [需求口径](01-requirements.md)。金额最多两位小数。

模型失败请检查 Ollama 是否运行、模型名和端点是否正确。页面默认读取本地 Qwen，CLI 则需显式设置 `.env.example` 所列环境变量；该文件不会自动加载。CPU 模型可能需要数分钟；单次 HTTP 最多 90 秒。达到模型步数上限表示未完成，成功步骤保留。

若整体显示失败或达到上限，但保存状态为“已保存”，说明方案已写入而模型收尾未完成；重复原请求会读取该方案。不要根据自由文本推断保存成功，以结构化保存状态、方案 ID 和列表为准。

Web 是本机工具，不对公网提供账户服务。不真实投放或发布，费用为模拟单位。线上部署不是考试必需，本项目未部署公网服务。
