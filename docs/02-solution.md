# 动态决策与持久状态

动作：select_plan(package)、search_materials、generate_script、estimate_cost、save_plan、finish(outcome)。选择计划是模型动作，四个业务工具对应检索、生成、估算、保存。模型每次拿到实际步骤状态与工具观察再决定下一步。

依赖：检索成功 → 对应套餐脚本成功 → 保存；执行付费工具前需要观察该计划的估算。估算可在检索前进行，以便发现 premium=12 超预算后改 basic=8，避免先花掉超预算费用。保存工具会重算预算、时限和依赖，不相信模型自由文本。

SQLite 每个工具动作使用事务更新状态、成功产物、尝试次数、累计实际费用与方案。成功步骤按工具+输入/套餐缓存；更换套餐不清空成功检索；失败脚本仍在历史中，重试可升级同一步但尝试事件保留。方案按 request_id 唯一。请求执行使用有期限的租约防止同键并发；正常结束释放，崩溃租约过期后可恢复。

工具费在成功事务内记账，写入失败回滚，不能报告成功；独立失败事件持久记录。没有真实外部副作用，因此事务能覆盖全部模拟工具。生产真实外部工具仍需业务幂等键及对账。

运行预算限制模型动作数；到上限返回 budget_exhausted，保留成功步骤。整体状态、步骤状态、保存状态分开。模型可请求结束，但完成/缺信息/无可行方案等终态必须有事实支持。

采用 Python 3.10+、标准库、SQLite 和 Ollama 本地 Qwen；沿用题一已验证的 HTTP 适配接口，独立代码副本，不修改题一或依赖其本地文件。Web 默认端口 8767，模型 API 仍在 11434；清楚区分网页与 API 地址。
