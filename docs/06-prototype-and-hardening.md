# 动作流与痛点强化

沿用用户已确认的方式交付可导入 Figma 的 SVG，不声称有 Figma 在线文件。

| 痛点 | 约束 | 强化测试 |
| --- | --- | --- |
| P1 缺输入被默认补齐 | 缺预算/截止直接待补充 | null、空白、非法日期 |
| P2 重规划抹成本 | 已发生费用不可逆，整数账本 | 先生成 premium 再换 basic、分币边界 |
| P3 依赖错乱/失败冒成功 | 服务端步骤守卫 | 跳过检索、保存失败、非法完成 |
| P4 重复收费或重复保存 | 成功步骤缓存、方案唯一 | 重复/并发/进程重启 |
| P5 续跑丢成功结果 | 状态持久化与故障次数持久化 | 一次失败跨进程续跑、部分成功 |
| P6 截止失真 | 真实时钟与累计模拟时间 | 恰好截止、跨日、已过期、模型延迟 |
| P7 不可行时空转 | 步数上限、真实缺口 | 所有方案超限、无限重试/非法动作 |

顺序：需求协议 → 图稿 → 最小真实决策 → 状态与费用工具 → 五必验与续跑 → 边缘困难强化 → Web/浏览器 → 最终证据。
